# Supabase Auth email templates (bilingual)

Paste each file into **Supabase → Authentication → Email Templates** (Source / HTML), with the subject below.
Links use `token_hash`, so they work even if opened in another browser (handled by `/auth/callback`).

| Template in Supabase | File | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Confirm your email / Bekräfta din e-postadress |
| Reset Password | `reset-password.html` | Reset your password / Återställ ditt lösenord |
| Change Email Address | `change-email.html` | Confirm your new email / Bekräfta din nya e-postadress |

Swedish copy should be proofread by a native speaker before launch.
